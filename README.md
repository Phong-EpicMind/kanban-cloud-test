# Kanban

Ứng dụng Kanban hiện đại, thuần HTML/CSS/JS — mở `index.html` là chạy.

- Kéo thả thẻ giữa các cột và sắp xếp thứ tự
- Thêm/sửa/xoá thẻ: mô tả, ưu tiên, hạn chót (cảnh báo quá hạn), nhãn
- Thêm/xoá/đổi tên cột (bấm đúp tiêu đề)
- Tìm kiếm (phím `/`) và lọc theo ưu tiên
- Giao diện sáng/tối, responsive
- Tự lưu vào localStorage
